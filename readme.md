# Bug Fixing Using Cursor AI

## Project Description
This project demonstrates how unclear Python code can be improved through code review and refactoring.

## Files

- `messy.py` — original code with unclear variable and function names.
- `improved.py` — refactored code with descriptive naming and a reusable function.
- `README.md` — project documentation.

## Improvements

- Removed an unused import.
- Replaced unclear function names with descriptive names.
- Used a reusable function to calculate the average.
- Used f-strings for output.
- Added a function docstring.
- Preserved the original printed output.

## How to Run
Install Python 3, open the project folder in VS Code, and run:

```bash
python messy.py
python improved.py
```

## Learning Outcome
Learned how to make Python code easier to read, maintain, and reuse.
